Data diringkas sekitar setiap 2 detik. Jika giroskop tidak tersedia, model akselerometer digunakan.

Cara mencoba

  1. Tekan Mulai deteksi, lalu izinkan sensor jika diminta.
  2. Letakkan HP diam selama 6–10 detik, lalu lihat hasilnya.
  3. Angkat atau gerakkan HP selama beberapa detik, lalu diamkan kembali.

Jaga layar tetap menyala dan halaman tetap terbuka. Di laptop atau HP yang tidak mendukung sensor, gunakan Mode simulasi.

Jika sensor belum terbaca

Buka tautan HTTPS langsung di Safari atau Chrome, bukan browser di dalam WhatsApp/Instagram. Periksa izin sensor gerak pada pengaturan situs. Sensor tidak tersedia pada semua perangkat; bila tetap tidak terbaca, coba browser lain atau Mode simulasi.

Untuk laporan tugas

Input gerakan HP → neural network MLP → DIAM / BERGERAK. Model dilatih menggunakan data simulasi berlabel; hasil nyata perlu diuji pada masing-masing HP.

CSV berisi prediksi dan fitur, bukan label kebenaran. Bedakan hasil sensor nyata dengan simulasi saat menyusun laporan.

Pemrosesan dilakukan di browser HP. Aplikasi ini tidak mengunggah data sensor. Tingkat keyakinan model bukan jaminan ketepatan. Yang dikenali adalah gerakan HP; ini bukan penilaian postur atau kesehatan.
